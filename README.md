# SRW Classic Animation Skip — Reverse Engineering Records

This repository contains reverse engineering records for classic *Super Robot Wars* (SRW) games whose battle animations originally cannot be skipped, along with documentation and patch sources for adding an option to skip those animations.

## No ROMs Provided

This repository **does not provide any ROM files**, game images, or copyrighted game data.

You must obtain and use your own legally owned copy of the game. Only patch scripts, assembly notes, and reverse engineering documentation are provided here.

## About the Patches

Each patch may target a specific game version, regional release, or ROM revision. Because different ROM versions and existing translations may have slightly different code layouts, the specific patch details, addresses, and behavior can vary.

For details, always read the introduction and documentation for the corresponding patch before applying it.

## Patch Compatibility

Patches are version-sensitive. A patch that works on one ROM revision may not work on another. If a patch does not apply or behaves unexpectedly, check the patch-specific notes and verify that your ROM matches the expected version.
