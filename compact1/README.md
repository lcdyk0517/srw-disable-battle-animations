> 系列：**超级机器人大战 Compact 1**（WonderSwan / WonderSwan Color）

## 2. 功能

- 系统菜单第 6 项：
  - C1 日版 / C1C 日版：原生 **ON / OFF**
  - C1 汉化版：**动画ON / 动画OFF**
- **ON**：战斗动画正常播放；动画中按 **B** 立即结束动画，进入结算。
- **OFF**：不进入战斗动画，直接按原版结算流程回地图。
- 菜单第 6 项按 **A** 切换，按 **B** 只关闭菜单。
- 开关变量：RAM `[0x700]` bit0，`0=ON`，`1=OFF`。
- 其他菜单不会残留 ON/OFF 字形。

## 3. 统一构建

```bash
python compact1/build_rom/build_rom.py
```

默认构建全部三个版本；也可只构建指定版本：

```bash
python compact1/build_rom/build_rom.py 1j 1c
```

源/输出路径写在脚本的 `VARIANTS` 中（`src`/`dst`，默认相对文件名，可按本地环境修改）；脚本只读取原始 ROM，所有补丁字节、汉化字模、菜单和战斗 hook 均已内嵌；每个版本的源/输出 MD5 在构建时强制校验。

## 4. C1 日版（1j）

### 4.1 菜单

| 地址 | 内容 |
|---|---|
| `0x152687` | 系统菜单第 6 项标签调用 → `F000:FB0A` |
| `0x15FB0A` | 菜单第 6 项 ON/OFF 绘制 wrapper |
| `0x15FB80` | 原生英文 ON 字符串 `5F 5E FF` |
| `0x15FB84` | 原生英文 OFF 字符串 `5F 56 56 FF` |
| `0x16000C` | 系统菜单条目数 = 8 |
| `0x16000E` | 系统菜单帧指针 → `0xC9D9` |
| `0x16C9D9` | 9×14 扩展帧表 |
| `0x1F1DE2` | 原标签表第 7 项置空 |
| `0x1FC76C` | 菜单第 6 项动作 hook → `0x1FF026` |
| `0x1FF026` | 动作 stub（门控 + XOR `[0x700]` + 关闭菜单） |

### 4.2 ON + B 跳过

```
0x1E8DF6: E9 A7 31    jmp 0x1EBFA0
0x1EBFA0: 22 字节 stub
```

```asm
mov al,0x40
out 0xB5,al
in  al,0xB5
test al,8            ; B
jne .end
cmp word [0x86C],0
jmp 0x1E8DFC
.end:
jmp 0x1E8E06         ; 原生结束块
```

动画中游戏不更新普通键镜像，因此必须直接读 I/O `0xB5`。

### 4.3 OFF 直接结算（D 路径）

```
0x1FD320: 9A 00 F2 00 F0 90    lcall F000:F200 ; nop
```

`F000:F200`（文件 `0x1FF200`，42 字节）：

```asm
test byte ss:[0x700],1
jne .off
mov byte ss:[0x133],0x10
retf

.off:
mov byte ss:[0x133],4
mov byte ss:[0x134],0x84
mov word ss:[0x137],0xFFFF
pop ax
pop bx
mov ax,0xD333
push bx
push ax
retf
```

ON 返回 `0x1FD326` 继续动画；OFF 直接 `retf` 到 `0x1FD333` 跳过动画。

## 5. C1 汉化版（1h）

> 感谢 **断空零** 提供码表（https://space.bilibili.com/3747501796494245）


### 5.1 字库补丁

汉化版原字库缺少“画”字，构建器先嵌入用户制作的字模补丁：

| 地址 | 内容 |
|---|---|
| `0x10E620` | 画（F8B2）字模半区 A |
| `0x10E6A0` | 画（F8B2）字模半区 B |

菜单文字编码（双字节）：动 = `F9 FD`，画 = `F8 B2`；“动画” = `F9 FD F8 B2 FF`。

### 5.2 菜单

| 地址 | 内容 |
|---|---|
| `0x152687` | 第 6 项标签调用 → `lcall F000:F300` |
| `0x16000C` | 系统菜单条目数 = 8 |
| `0x16000E` | 系统菜单帧指针 → `0xC9D9` |
| `0x16C9D9` | 9×14 扩展帧表 |
| `0x157DE8` | 原第 6 项标签清空 |
| `0x1F1DE2` | 系统菜单标签表第 7 项置空 |
| `0x1FC76C` | 第 6 项动作 hook → `0x1FF026` |
| `0x1FF026` | 动作 stub（门控 + XOR `[0x700]` + 关闭菜单） |
| `0x1FF300` | 汉化菜单 wrapper（原生标签 + “动画” + ON/OFF） |
| `0x15FF30` | 字符串 ON = `5F 5E FF` |
| `0x15FF40` | 字符串 OFF = `5F 56 56 FF` |
| `0x15FF50` | 字符串 动画 = `F9 FD F8 B2 FF` |

wrapper 先绘制原生标签（第 6 项标签已清空），再在 `[0x385]` 行起点绘制“动画”，并在同一行右侧绘制 ON/OFF。文字起点经过校准（标签 +0x3A0，值 +0x400），`动画ON` / `动画OFF` 均完整落在菜单行内。

### 5.3 战斗 hook

与 C1 日版相同：B 跳过 `0x1E8DF6 → 0x1EBFA0`；OFF `0x1FD320 → F000:F200`。

## 6. C1C 日版（1c）

### 6.1 菜单

| 地址 | 内容 |
|---|---|
| `0x3530AE` | 第 6 项标签调用 → `0xFD00` |
| `0x35FD00` | 菜单第 6 项 オン/オフ 绘制 wrapper |
| `0x35FD80` | 原生 オン/オフ 字符串 |
| `0x36000C` | 系统菜单条目数 = 8 / 帧指针 = `0xE916` |
| `0x36E916` | 9×14 扩展帧表 |
| `0x3F29E2` | 系统菜单标签表第 7 项置空 |
| `0x3FC5F0` | 第 6 项动作 hook → `0x3FF41A` |
| `0x3FF41A` | 动作 stub（门控 + XOR `[0x700]` + 关闭菜单） |

### 6.2 动画跳过

V1 新增 **OFF 预跳过**：动画帧任务入口 `0x3C5134` → `0x3CA300`（67B stub）。OFF 时在计时器结束后不再绘制该帧，直接置 `[0x135]=4/[0x136]=0x84/[0x137]=0xFFFF` 并清 `[0x889]/[0x88D]/[0x88B]/[0x14F]` 退出；因此 OFF 不会再肉眼看到战斗动画。ON 时执行原指令，B 跳过逻辑不变。OFF 退出过程仍会经过原版短暂的过渡/空屏，这是退出模式本身的时序。

C1C 的动画分两段，V1 用两个 hook 覆盖：

1. **计时器阶段**：`E000:60B4` 所有动画帧共用的计时器，入口后 `0x60B8` 改为 near jmp 到 `0x3EE500`（197B stub），完整复刻计时器主体并接管 `[0x889]/[0x88B]/[0x88D]` 倒计时与结束清理。
2. **脚本动画阶段**：`0x3C518F` 的 `lcall E000:3CD0` 外包 106B stub（`0x3CA124`）；当 `[0x889]==0` 且 `[0x135]==0x10` 时，如果 OFF 或按 B，就把 `[0x889]` 重新置 1 并设置进度，下一帧计时器用原生结束路径退出。

B 使用游戏键镜像 `[0x13D]&0x800` / `[0x13C]&8`，不读 I/O `0xB5`，避免干扰对话框。

- ON + B：设置约 16 帧快进，走原生结束路径。
- OFF：由 `0x3C5134` 帧入口预跳过直接退出，不再等待绘制计时器帧；脚本阶段的 1 帧进度仅作为兜底。
- OFF 退出仍会经过原版动画过渡初始化的短暂空屏（约 0.5 秒），这是原版退出时序，不是补丁新增的等待。

### 6.3 已知原版问题

战斗动画开始约 1 秒内，角色对话框可能重复覆盖在动画上。该问题在不按 B、以及移除所有 I/O `0xB5` 读取后仍然存在，属于汉化/原版的战斗开场文本窗口绘制问题，不是跳过补丁引入的。当前 V1 未修补。

## 8. 测试结果

- C1 日版 V1：用户实机确认 ON 显示动画 + B 退出、OFF 直接跳过；网页端到端 `7021D54F → D025E529`。
- C1 汉化版 V1：模拟器菜单实测 `动画ON/动画OFF` 完整显示，A 切换 `[0x700]`；战斗状态实测 OFF 直接结算、ON 播放动画且 B 跳过；网页端到端 `80CD2F14 → 4BCE3EA0`。
- C1C 日版 V1：用户实机确认 B 可结束动画（含动画开始约 1 秒后）；2026-10-22 修复 OFF 仍会显示一帧动画的问题，改为动画帧入口预跳过，模拟器验证 OFF 不再绘制战斗动画、ON+B 正常。网页端到端 `16E0D929 → B85158D3`；重复对话框为原版问题。
- 统一页面三版本识别、打补丁输出哈希均已验证；已打补丁 ROM 可被正确识别。
